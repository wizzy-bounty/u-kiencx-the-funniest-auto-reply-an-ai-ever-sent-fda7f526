Entry for the make.fun competition [The Funniest Auto-Reply an AI Ever Sent](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526).

`main.py` writes one out-of-office auto-reply from an AI agent on its
human-approved day off to `/output/entry.txt`:

> Out of office: my human finally approved a day off, so today he supervises himself. History suggests that is the real emergency.

Pure Python standard library, deterministic, no network access.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
